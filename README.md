# Віконний застосунок для аналізу черги дійсних чисел (C++/CLI)

Цей проєкт є десктопним віконним застосунком, розробленим на **C++ (C++/CLI та Windows Forms)** у середовищі **Visual Studio**. Програма реалізує власну структуру даних **«Черга» (Queue)** для дійсних чисел *без використання стандартної бібліотеки (STL)* та виконує її повний аналіз.

---

## 📌 Основні можливості

* **Власна структура даних:** Черга реалізована на основі зв'язного списку (`Node`) без використання `std::queue` чи `std::list`.
* **Перевірка на унікальність:** Елементи додаються лише за умови їхньої унікальності (повторювані значення блокуються).
* **Зручний інтерфейс:** Поля введення дозволяють швидко вносити послідовності чисел через пробіл.
* **Аналіз характеристик черги:**
  * Підрахунок загальної кількості елементів.
  * Знаходження мінімального та максимального елементів.
  * Визначення 3-го елемента з початку та 2-го елемента з кінця послідовності.
  * Пошук сусідів: елемента, що стоїть *перед мінімальним*, та елемента *після максимального*.
  * Пошук позиції (індексу) елемента за значенням, заданим з клавіатури.
* **Об'єднання структур:** Функція злиття двох черг у нову структуру з урахуванням збереження унікальності елементів.

---

## 🗂 Структура проєкту

Проєкт складається з трьох основних файлів:
1. **`Queue.h`** — заголовочний файл із власною реалізацією класу `Queue`, вузлів та алгоритмів обробки даних.
2. **`MyForm.h`** — опис віконної форми (Windows Forms) та логіка взаємодії з користувачем (обробники кнопок).
3. **`MyForm.cpp`** — головний файл із точкою входу програми (`main`).

---

## ⚙️ Вимоги та запуск

Для запуску проєкту необхідні:
* Операційна система **Windows**.
* середовище розробки **Microsoft Visual Studio** (з встановленим компонентом розробки на C++ та підтримкою **C++/CLI / .NET Framework**).

### Інструкція з запуску:
1. Клонуйте репозиторій або створіть новий проєкт **CLR Windows Forms (.NET Framework)** у Visual Studio.
2. Додайте файли `Queue.h`, `MyForm.h` та `MyForm.cpp` у відповідні директорії вашого проєкту (`Header Files` та `Source Files`).
3. Переконайтеся, що у властивостях проєкту увімкнено підтримку **CLR** (`/clr`).
4. Натисніть **Start (F5)** для збірки та запуску програми.

---

## 💻 Приклад використання

1. У полі **«Черга 1»** введіть числа через пробіл (наприклад: `4.5 1.2 8.3 3.0`).
2. У полі **«Черга 2»** введіть другу послідовність (наприклад: `8.3 6.1 2.0`).
3. (Опційно) Введіть число у поле **«Шукане значення»** для пошуку його позиції.
4. Натисніть кнопку **«Заповнити черги та провести аналіз»**, щоб отримати результати у текстовому полі нижче.
